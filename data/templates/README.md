# قوالب البيانات — املأ ما لديك فقط

## ١) `prices-template.csv` — إدخال الأسعار الحقيقية (493 منتجًا)

الملف يحتوي **كل المنتجات الموجودة** بأعمدة:

```
generic_name, trade_name, strength, barcode, price, currency
```

عمود `price` **فارغ بالكامل** — لا يحتوي أي سعر وهمي. املأه فقط بالأسعار الحقيقية التي تعرفها:

1. افتح الملف في Excel أو Google Sheets (UTF‑8 مع BOM — الحروف العربية تظهر سليمة).
2. اكتب السعر في عمود `price` (أرقام فقط، بالريال اليمني، مثال: `1500`).
   - اتركه فارغًا لأي دواء لا تعرف سعره — **لن يُغيَّر ولن يُخترع له سعر**.
3. احفظ الملف بصيغة **CSV UTF‑8**.
4. لوحة الإدارة → **الاستيراد** → ارفع الملف → **معاينة (dry-run)** → تأكد من عدد التحديثات → **تنفيذ**.
5. بعد الاستيراد: **الإعدادات → إعادة بناء فهرس البحث** (سطر واحد) لتحديث البحث.

### ماذا يحدث للصفوف؟
- المطابقة: `generic_name` (الدواء) + `trade_name` + `strength` (المنتج) — لذا لا تُنشأ منتجات مكرّرة.
- المنتج الموجود يُحدَّث سعره فقط؛ الحقول الأخرى تبقى كما هي (الاستيراد يستخدم `COALESCE`).
- الأعمدة الفارغة لا تمسح بيانات موجودة.

> ⚠️ لا تحذف الأعمدة `generic_name` أو `trade_name` — بها يتم التعرف على المنتج.
> عمود `barcode` موجود للتحقق فقط، ويمكن تركه كما هو.

### فائدة إضافية
يمكنك أيضًا إضافة سعر **الدواء العام** في التطبيق عبر نفس الآلية لاحقًا، أو تعديل سعر منتج واحد يدويًا من
**لوحة الإدارة → الكتالوج → تعديل المنتج**.

## ٢) قالب إضافة أدوية جديدة

استخدم نفس أعمدة `docs/IMPORT.md` (الاسم العلمي إلزامي، والباقي اختياري):

```csv
generic_name,generic_ar,trade_name,trade_name_ar,strength,dosage_form,pack_size,manufacturer,country,agent,barcode,price,currency,system,category
metformin,ميتفورمين,Glucophage,جلوكوفاج,500 mg,Tablet,30 tablets,Merck,France,وكيل يمني,5012345678901,,YER,endocrine,antidiabetics
```

- السعر اتركه فارغًا إن لم يكن حقيقيًا.
- `system` يقبل الاسم العربي أو الإنجليزي أو `slug` (مثل `cardiovascular`, `respiratory`, `endocrine`).
- `agent` = الوكيل/الموزّع اليمني (يُنشأ تلقائيًا إن لم يوجد).

ويمكن التراجع عن صفوف خاطئة يدويًا من الكتالوج.
