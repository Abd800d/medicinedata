# تسجيل الدخول بحساب Google — دليل كامل

هذا الدليل يجيب عن سؤال: **كيف أسجّل التطبيق في Google ليصبح فيه زر «الدخول بحساب Google»؟**

> ملاحظة مهمة أولًا: **الحسابات تُحفظ على خادم MDA**. بدون نشر الخادم لا يوجد مكان يُحفظ فيه الحساب،
> لا بالبريد ولا بجوجل. خطوة ١ إلزامية.

---

## ٠) قبل أي شيء — ترتيب صحيح

```text
① انشر الخادم (Render/VPS)   →  ② أنشئ حساب المدير (تلقائيًا)  →  ③ سجّل OAuth في Google
   →  ④ الصق Client ID في لوحة التحكم  →  ⑤ زر جوجل يعمل فورًا
```

**الخطوة ② والخطوة ③ لا تحتاج كودًا** — لا تحتاج إعادة بناء التطبيق ولا تحديثًا.

---

## ١) الحسابات الثلاثة في التطبيق — ما الفرق؟

| الحساب | كيف يُنشأ | ما يستطيع |
|---|---|---|
| **حساب المالك / المدير** | تلقائيًا عند أول تشغيل للخادم: البريد `OWNER_EMAIL` وكلمة المرور `ADMIN_PASSWORD` | كل شيء: لوحة التحكم `/admin`، إضافة/تعديل أدوية، استيراد، صور، أسعار، إعدادات |
| **حساب مستخدم** | من داخل التطبيق: تبويب **إنشاء حساب** (اسم + بريد + كلمة مرور ٦+) | المجتمع، الوظائف، الصيدلية، الوصفات، المفضلة |
| **حساب Google** | ضغطة زر واحدة **بعد** تسجيل OAuth (بقية هذا الدليل) | نفس صلاحيات المستخدم، بدون كلمة مرور |

بيانات المدير الافتراضية إن لم تضبط متغيرات:
`7a8b1d@gmail.com` · كلمة المرور: التي أدخلتها في `ADMIN_PASSWORD` عند النشر.

تغيير كلمة مرور المدير من داخل التطبيق: **الملف الشخصي ← تغيير كلمة المرور**.
تعطيل التسجيل مؤقتًا: **لوحة التحكم ← الإعدادات ← السماح بالتسجيل = لا**.

## ٢) تسجيل التطبيق في Google Cloud (مرة واحدة، ~٧ دقائق)

### أ) إنشاء مشروع
1. افتح <https://console.cloud.google.com/projectcreate>.
2. اسم المشروع: `MDA Medicine Data` ← **Create**.
3. تأكد أن المشروع الجديد هو المحدد في أعلى الصفحة.

### ب) شاشة الموافقة (OAuth consent screen)
1. <https://console.cloud.google.com/apis/credentials/consent>
2. **External** ← **Create**.
3. املأ:
   - App name: `MDA — Medicine Data`
   - User support email: `7a8b1d@gmail.com`
   - Developer contact: `7a8b1d@gmail.com`
4. **Save and continue** ← Scopes: اتركها فارغة ← **Save**.
5. Test users: أضف بريدك (`7a8b1d@gmail.com`) ← **Save**.
   > في وضع *Testing* يعمل الدخول لحسابات Test users فقط (حتى ١٠٠). للنشر العام اضغط **Publish app**
   > ثم املأ صفحة التحقق إن طلبتها Google (عادةً تحتاج للنطاق + سياسة خصوصية).

### ج) إنشاء OAuth Client (النوع المهم: **Web application**)
1. <https://console.cloud.google.com/apis/credentials> ← **Create credentials** ← **OAuth client ID**.
2. Application type: **Web application**.
3. Name: `MDA Web`.
4. **Authorized JavaScript origins** — أضف بالضبط:
   ```text
   https://mda.onrender.com        ← رابط خادمك بعد النشر (أو نطاقك الخاص)
   http://localhost:4000           ← للتجربة على جهازك
   https://localhost               ← تطبيق أندرويد (Capacitor WebView)
   ```
   > لا تضع مسارًا (`/admin`) ولا شرطة أخيرة — النطاق فقط. أي خطأ هنا يظهر كـ
   > `Error 400: origin_mismatch` في المتصفح.
5. **Create** ← انسخ **Client ID** (يشبه `1234567890-abcdef.apps.googleusercontent.com`).
   > لا تحتاج الـ Client secret إطلاقًا (نستخدم ID Token وليس code flow).

### د) (اختياري — لأندرويد) OAuth client من نوع Android
1. **Create credentials** ← **OAuth client ID** ← **Android**.
2. Package name: `com.mda.medicinedata`
3. SHA-1: بصمة مفتاح التوقيع. تظهر في سجل البناء على GitHub:
   **Actions → آخر تشغيل ناجح → خطوة «Verify signature»** (أو Issue «APK signing report»).
4. **Create**.
   > هذا مطلوب فقط للدخول الأصلي داخل التطبيق (بدون WebView) — انظر القسم ٥.

## ٣) تفعيل الزر داخل التطبيق (بدون إعادة نشر)

1. ادخل لوحة التحكم: `https://رابط-خادمك/admin` بحساب المدير.
2. **الإعدادات** ← حقل **Google Client ID** ← الصق المعرّف ← **حفظ**.
3. افتح التطبيق ← **الحساب** ← سيظهر زر Google الرسمي.
   > أثناء الاختبار تظهر رسالة «Google hasn't verified this app» ← **Continue** (طبيعي في وضع Testing).

القيمة تُحفظ في قاعدة البيانات، ويقرأها الخادم من `settings.google_client_id`، لذا لا تحتاج
تعديل `.env` ولا إعادة تشغيل. للتفعيل عبر البيئة بدلًا من اللوحة:
`GOOGLE_CLIENT_ID=...` في متغيرات الخادم (له الأولوية إن وُجد).

## ٤) كيف أتحقق أنها تعمل؟

| الاختبار | النتيجة المتوقعة |
|---|---|
| `GET https://رابط-خادمك/api/config` | `"google_client_id": "1....apps.googleusercontent.com"` |
| صفحة الدخول | زر Google الرسمي (ليس المربع المنقّط) |
| الضغط عليه | نافذة اختيار حساب Google |
| بعد الاختيار | تعود للتطبيق مسجلًا، ويظهر الاسم في «المزيد» |
| لوحة التحكم ← المستخدمون | الحساب الجديد موجود بدور `user` |

أعطال شائعة:

| الرسالة | السبب | الحل |
|---|---|---|
| `origin_mismatch` | النطاق غير مضاف في Authorized JavaScript origins | أضِف النطاق حرفيًا (بدون مسار) |
| `Google Sign-In غير مُفعّل بعد` | الحقل فارغ في اللوحة | الصق Client ID واحفظ |
| `Google audience mismatch` | Client ID في اللوحة ≠ المستخدم في المتصفح | تأكد أنه نفس المعرّف |
| الزر لا يظهر في الـAPK | Google يحظر OAuth داخل WebView | راجع القسم ٥ |

## ٥) تطبيق الأندرويد — ما يعمل وما لا يعمل

Google **ترفض عمدًا** تسجيل الدخول داخل WebView (`disallowed_useragent`) لحماية المستخدم.
لذلك في نسخة الـAPK الحالية:

- ✅ الدخول بالبريد وكلمة المرور يعمل.
- ⛔ زر Google (المبني على Web) لا يعمل داخل التطبيق.
- الحل الصحيح: **تسجيل أصلي** عبر حساب الجهاز (Credential Manager) ثم إرسال `idToken`
  إلى نفس المسار `/api/auth/google` — يحتاج إضافة إضافية إلى مشروع أندرويد وإعادة بناء APK،
  ولا يحتاج تغييرًا في الخادم.

---

## ٦) الخلاصة في سطرين

- **الحساب** = على الخادم؛ يُنشأ من التطبيق (بريد) أو تلقائيًا للمدير.
- **جوجل** = سجّل OAuth Client من نوع *Web application*، أضف نطاقك، والصق المعرّف في لوحة التحكم — ينتهي الأمر.
