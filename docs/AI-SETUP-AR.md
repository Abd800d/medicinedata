# ربط التطبيق بالذكاء الاصطناعي — كل خطوة برابطها

> هذه الصفحة هي النسخة الكاملة من المحتوى الموجود داخل التطبيق في
> **المزيد ← دليل ربط الذكاء الاصطناعي** (`/ai-guide`). كل رابط هنا قابل للنقر،
> وكل أمر قابل للنسخ كما هو.

**الخلاصة في سطر:** الذكاء الاصطناعي **مبني داخل التطبيق بالفعل**؛ الذي ينقصك هو **مفتاح واحد مجاني**
تضعه على الخادم من داخل التطبيق. لا تحتاج بناء APK جديد، ولا إعادة تشغيل، ولا كمبيوتر.

## 3 — الطريق الثاني: من الخادم (`.env`)

مناسب إن كنت تدير الخادم بنفسك (لابتوب أو Render):

```bash
# 1) داخل مجلد المشروع
cp .env.example .env

# 2) عدّل هذه الأسطر داخل .env
JWT_SECRET=<96 حرفًا عشوائيًا>          # يُنصح به دائمًا (لم يعد إلزاميًا بعد 1.10.2)
AI_PROVIDER=groq
AI_API_KEY=gsk_xxxxxxxxxxxxxxxxxxxx
AI_MODEL=openai/gpt-oss-120b
AI_VISION_MODEL=meta-llama/llama-4-scout-17b-16e-instruct

# 3) أعد التشغيل
npm run dev        # تطوير
npm start          # إنتاج
```

توليد `JWT_SECRET`:

```bash
node -e "console.log(require('crypto').randomBytes(48).toString('hex'))"
```

**على Render:** لوحة التحكم ← الخدمة ← **Environment** ← أضف نفس المتغيرات ← Save (يعيد النشر تلقائيًا).

**الأولوية:** ما تحفظه من التطبيق (قاعدة البيانات) يتقدّم على `.env`؛ و`.env` يتقدّم على قالب المزوّد.
يُقرأ الإعداد عند **كل طلب**، فلا حاجة لإعادة تشغيل بعد التغيير من التطبيق.

## 4 — التحقق: كيف تعرف أنه يعمل فعلًا

```bash
# أ) هل الخادم يرى المفتاح؟
curl -s https://<خادمك>/api/ai/status
#   مفعّل:   {"enabled":true,"provider":"groq","model":"openai/gpt-oss-120b",...}
#   معطّل:   {"enabled":false,"provider":"offline-database","model":null,"hint_ar":"..."}

# ب) هل تحليل الوصفات مفعّل؟
curl -s https://<خادمك>/api/rx/status
#   {"configured":true,...,"features":{"prescription":true,"pack_recognition":true,...}}

# ج) فحص محلي شامل (يشمل قابلية تخزين المفتاح)
npm run doctor
#   ✓ AI can be enabled from the app → can_store=true configured=… provider=… model=…

# د) اختبار حقيقي مربوط بالمفتاح (يحتاج توكن مدير)
curl -s -X POST https://<خادمك>/api/admin/ai/test \
  -H "authorization: Bearer <TOKEN>" -H 'content-type: application/json' -d '{}'
#   {"ok":true,"latency_ms":162,"provider":"groq","model":"openai/gpt-oss-120b","sample":"ok"}
```

**على الجهاز:** بعد التفعيل يجب أن تختفي بطاقة «الذكاء الاصطناعي غير مفعّل» من شاشتي الوصفات والمساعد،
وتظهر النتائج من المزوّد (`mode: "ai"` بدل `mode: "offline-database"`).

## 5 — أين يظهر الذكاء الاصطناعي في التطبيق

| الشاشة | ما يفعله | بلا مفتاح |
| --- | --- | --- |
| [المساعد الذكي `/ai`](/ai) | سؤال بلغة طبيعية، جواب من قاعدة MDA بالمراجع | يعمل بالبحث المحلي: `mode: "offline-database"` — بلا خطأ |
| [الوصفات `/prescriptions`](/prescriptions) | صورة وصفة → بنود + جرعات + تنبيهات حساسية من قاعدة البيانات | يظهر تنبيه مع زر التفعيل للمدير |
| [المسح `/scan`](/scan) | صورة علبة → أقرب منتجات في القاعدة | تنبيه مع زر التفعيل |

**قاعدة ثابتة:** لا اعتماد آلي — `auto_accepted = 0` و`requires_pharmacist = true` في كل تحليل،
وكل بند يمرّ على [طابور مراجعة الصيدلي](/review).

## 6 — إن فشل الاختبار: الرسالة ← المعنى ← الحل

| `kind` | المعنى | ما تفعله |
| --- | --- | --- |
| `no-key` | لا يوجد مفتاح محفوظ | الصق المفتاح واحفظ |
| `auth` | المفتاح غير صحيح أو منتهٍ (401/403) | [أنشئ مفتاحًا جديدًا](https://console.groq.com/keys) |
| `model` | اسم الموديل غير متاح لهذا المفتاح | اضغط **«استخدم البديل الآن»** أو اكتب `openai/gpt-oss-120b` |
| `quota` | تجاوزت الحصة المجانية (429) | انتظر دقيقة، أو بدّل المزوّد |
| `request` | المزوّد رفض صيغة الطلب (400) | جرّب موديلًا يدعم JSON |
| `network` / `timeout` | الخادم لا يصل إلى المزوّد | افحص اتصال الخادم، أو استخدم مزوّدًا آخر |
| `upstream` | خطأ 5xx من المزوّد | أعد المحاولة |
| `NO_SECRET` (عند الحفظ) | الخادم بلا مادة تشفير | حدّث إلى **1.10.2+**، أو اضبط `JWT_SECRET`، أو تأكد أن `data/` قابل للكتابة |
| `can_store=false` | لا يمكن تشفير المفتاح | نفس الحل أعلاه |

## 7 — التكلفة والحدود (بصدق)

| المزوّد | الحد المجاني التقريبي | ملاحظة |
| --- | --- | --- |
| Groq | ~30 طلبًا/دقيقة · 1000–14,400 طلبًا/يوم (يختلف بحسب الموديل) | الأسرع، ويكفي للاستخدام اليومي العادي |
| Gemini | ~10–15 طلبًا/دقيقة · ~1000–1500 طلبًا/يوم | يدعم الصور بموديل واحد |
| حد داخل التطبيق | **25 طلبًا/دقيقة لكل مستخدم** على `/api/ai/*` | حماية من الاستهلاك المفاجئ |

حدود حقيقية أخرى: لا OCR على الجهاز (التحليل يحتاج إنترنت + خادم)، والنماذج المجانية قد تتأخر أو تفشل
فيُعاد المحاولة تلقائيًا (2 محاولات + مهلة 45 ثانية).

## 8 — الخصوصية

- المفتاح **يُخزَّن مشفّرًا** (AES-256-GCM بمفتاح مشتق عبر scrypt) في قاعدة الخادم، ولا **يُعاد لأي عميل**؛
  الواجهة تعرض قناعًا فقط مثل `gsk_…cdef`.
- لا مفاتيح ولا عناوين مزوّدين داخل الـAPK أو في الكود أو في المتصفح.
- كل حفظ/اختبار يُسجَّل في [سجل التدقيق](/admin?tab=audit) بالمزوّد والموديل والنتيجة — **بلا محتوى طلبات**.
- `/api/ai/status` و`/api/rx/status` عامّان لكنهما لا يحملان أي مفتاح أو عنوان مزوّد.
- تغيير `JWT_SECRET` يُبطل المفتاح المحفوظ (يُعاد لصقه) — هذا سلوك مقصود وآمن.

## 9 — أسئلة سريعة

**هل أحتاج إعادة تثبيت التطبيق بعد التفعيل؟** لا. الإعداد على الخادم ويُقرأ عند كل طلب.

**هل يعمل على الأندرويد والويب؟** نعم، نفس الخادم ونفس الشاشة.

**هل يعمل بلا إنترنت؟** لا للتحليل. التصفح والبحث والكتالوج تعمل من الحزمة المدمجة.

**هل يمكن لمستخدم عادي تفعيله؟** لا، شاشة التفعيل للمدير فقط؛ المستخدم العادي يرى زر «دليل الربط».

**ما أسرع طريق إن كان الخادم على Render المجاني؟** قد يستغرق أول طلب 30–60 ثانية (استيقاظ)،
والتطبيق يعلن ذلك بـ «الخادم يستيقظ» بدل «لا اتصال».
