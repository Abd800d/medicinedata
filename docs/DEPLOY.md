# نشر الموقع (لوحة التحكم) وربطه بالتطبيق

الموقع الذي تتحكم من خلاله هو نفس مشروع MDA: يخدم الواجهة العامة + **لوحة التحكم `/admin`** + الـ API + قاعدة SQLite.
الملفات الجاهزة للنشر: `Dockerfile` و`render.yaml`.

---

## ١) أسرع طريقة: Render (نشر بنقرة)

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/Abd800d/medicinedata)

> من الزر أعلاه (أو **New → Blueprint**) يقرأ Render ملف `render.yaml` وينشئ الخدمة + القرص الدائم.

### مهم قبل النشر: اختر الخطة
| الخطة | البيانات | الملاحظة |
|---|---|---|
| **Starter** ($7/شهر) | قرص دائم 1GB | الموصى بها: كل ما تضيفه من أدوية/صور/أسعار يبقى محفوظًا |
| **Free** | مؤقتة | احذف بلوك `disk:` واجعل `plan: free` — الكتالوج يُبذر تلقائيًا عند كل تشغيل، لكن تعديلاتك تُفقد |

1. ادخل [render.com](https://render.com) → **New → Blueprint** → اختر مستودع `Abd800d/medicinedata`.
2. Render يقرأ `render.yaml` وينشئ خدمة `mda` (Docker) + قرصًا دائمًا في `/app/data`.
3. عند الطلب، أدخل قيمة `ADMIN_PASSWORD` (كلمة مرور لوحة التحكم). بقية القيم مضبوطة.
4. بعد أول تشغيل (٢–٤ دقائق) يصبح الرابط مثل:
   `https://mda.onrender.com`
5. افتح `https://mda.onrender.com/admin` وسجّل الدخول:
   - البريد: `7a8b1d@gmail.com`
   - كلمة المرور: التي أدخلتها في `ADMIN_PASSWORD`

> أول تشغيل يبذر القاعدة تلقائيًا (18 جهازًا، 137 تصنيفًا، 225 دواءً، 493 منتجًا، 18 صورة علبة حقيقية)
> لأن `AUTO_SEED=1`. البيانات تُحفظ في `/app/data/mda.db` على القرص الدائم.

### بديل: Docker على أي VPS

```bash
git clone https://github.com/Abd800d/medicinedata.git && cd medicinedata
cp .env.example .env        # عدّل JWT_SECRET و ADMIN_PASSWORD
docker build -t mda .
docker run -d --name mda -p 4000:4000 -v mda-data:/app/data --env-file .env --restart unless-stopped mda
```

ثم ضع Nginx/Caddy أمام المنفذ 4000 مع شهادة HTTPS (مثال Caddy):
```
mda.example.com {
    reverse_proxy 127.0.0.1:4000
}
```

## ٢) ربط تطبيق الأندرويد بالموقع

بعد أن يصبح لديك رابط HTTPS عام:

**الطريقة السريعة (بدون إعادة بناء):**
1. افتح التطبيق → **المزيد ← الخادم والاتصال**.
2. ضع الرابط (مثل `https://mda.onrender.com`) → **اختبار الاتصال** → **حفظ وإعادة تحميل**.

**الطريقة الثابتة (داخل الـ APK):**
- Actions → **Android APK** → Run workflow → `api_base = https://mda.onrender.com`
- أو اضبط متغيّر المستودع `VITE_API_BASE` بنفس القيمة، ثم أنشئ وسمًا `v1.0.1` لبناء نسخة جديدة.

## ٣) ما تتحكم به من لوحة `/admin`

| التبويب | الوظائف |
| --- | --- |
| النظرة العامة | إحصاءات القاعدة، أكثر عمليات البحث، حالة الصور والذكاء الاصطناعي، أدوات الصيانة والتصدير |
| الكتالوج | إضافة/تعديل/حذف الأدوية والمنتجات والأجهزة والتصنيفات، الاستيراد الجماعي (CSV/Excel)، إدارة الصور والباركود |
| الوسائط | رفع صور المنتجات، الصور المصغّرة، جلب تلقائي من Google CSE عند ضبط المفاتيح |
| الناس | المستخدمون، مواضيع المجتمع، حالاتها |
| الطلبات | مراجعة الأدوية المرسلة من المستخدمين (قبول/رفض) |
| التكاملات | فحص Google / AI / CSE وحالة كل تكامل |
| الإعدادات | بيانات التواصل، الإحصاءات، إعدادات الموقع |

## ٤) متغيّرات البيئة المهمة

| المتغيّر | الوظيفة |
| --- | --- |
| `PORT` / `HOST` | منفذ وعنوان الاستماع (`4000` / `0.0.0.0`) |
| `DATA_DIR` | مكان `mda.db` و`uploads` (افتراضيًا `./data`) — ضعه على قرص دائم |
| `JWT_SECRET` | توقيع الجلسات — قيمة طويلة عشوائية |
| `ADMIN_PASSWORD` | كلمة مرور حساب المدير عند أول بذر |
| `OWNER_EMAIL` / `OWNER_NAME` | بيانات المالك الظاهرة في «حول» |
| `WHATSAPP_NUMBER` / `SUPPORT_EMAIL` | أزرار التواصل |
| `AUTO_SEED` | `1` لبذر القاعدة تلقائيًا عند أول تشغيل |
| `AI_API_KEY` | (اختياري) تفعيل المساعد الذكي وقراءة الوصفات بالصور |
| `GOOGLE_CLIENT_ID` | (اختياري) تسجيل الدخول بجوجل |
| `GOOGLE_CSE_KEY` / `GOOGLE_CSE_CX` | (اختياري) جلب صور المنتجات تلقائيًا |

كل التفاصيل في `docs/ENV.md`.

## ٥) ملاحظات

- **الأسعار**: الحقل موجود في القاعدة لكنه فارغ. لا تُعرض أي أسعار وهمية؛ عند إدخال أسعار حقيقية من لوحة التحكم (أو استيراد CSV) تظهر مباشرة في البطاقات.
- **النسخ الاحتياطي**: من لوحة التحكم ← «تصدير قاعدة البيانات»، أو انسخ `/app/data` كاملة (تشمل الصور المرفوعة).
- **HTTPS مطلوب** لتطبيق أندرويد (لا يعمل `http://` مع Capacitor)، ولذلك استخدم Render/Caddy أو أي مزوّد بشهادة.
- لو أردت نطاقك الخاص: أضِف `CNAME` إلى المزوّد ثم شهادة تلقائية.
