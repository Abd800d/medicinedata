# الحسابات: الأدوار · الاستعادة · الحذف النهائي (v1.9.1)

## الأدوار

| الدور | يصل إلى | يستطيع |
|---|---|---|
| `user` | التطبيق | البحث، المفضلة، الوصفات، المجتمع، صيدليتي |
| `pharmacist` | + `/review` | فتح وصفات المستخدمين، تصحيح البنود، اعتماد/رفض |
| `admin` | + `/admin` | كل شيء: الكتالوج، الاستيراد، المستخدمون، التدقيق، الإعدادات |

يُرقّي المدير أي حساب من **لوحة التحكم ← المستخدمون والرسائل ← تغيير الدور**.
كل ترقية/تعطيل/حذف يُسجَّل في سجل التدقيق باسم المنفّذ ووقته.

## نسيت كلمة المرور — المسار الذي يعمل فعلًا

هذا النشر **بلا بريد صادر**، لذلك لا شاشة تقول «أرسلنا لك رابطًا» كذبًا.
المسار الحقيقي (شاشة `/forgot-password`):

1. المستخدم يضغط **«نسيت كلمة المرور؟»** تحت حقل كلمة المرور في `/auth`.
2. يكتب بريده ← زر واتساب يفتح محادثة الدعم برسالة جاهزة تحمل البريد.
3. المدير يتحقق من الملكية، ثم من **المستخدمون والرسائل** يصدر **كلمة مرور مؤقتة**
   (`POST /api/admin/users/:id/password`).
4. المستخدم يدخل بها ويغيّرها فورًا من **حسابي ← كلمة المرور** (`POST /api/auth/change-password`).

> المدير **لا يحتاج** كلمة المرور القديمة ولا يطلبها. من يطلبها منك ينتحل صفة الدعم.

**لماذا لا يوجد رابط بالبريد؟** لا SMTP ولا نطاق مرسل. عند إضافة مزوّد بريد لاحقًا يكفي
ربط `POST /api/auth/forgot` + `POST /api/auth/reset` بنفس جدول المستخدمين؛ الشاشة الحالية صُمّمت
لتُستبدل بلا تغيير في بقية التطبيق.

## حذف الحساب (حق الإمحاء)

من **حسابي ← حذف الحساب نهائيًا** (بطاقة حمراء أسفل الصفحة).

| الحماية | التفصيل |
|---|---|
| تأكيد مكتوب | يجب كتابة `DELETE` حرفيًا |
| كلمة المرور | مطلوبة للحسابات المحلية (حسابات Google لا كلمة مرور لها) |
| حساب المالك | `7a8b1d@gmail.com` محمي دائمًا (`owner-protected`) |
| آخر مدير | يُرفض الحذف إن لم يوجد مدير آخر نشط (`last-admin`) |

**ما يُحذف فعليًا من الخادم:**

- سجل المستخدم نفسه، والمفضلة، ومخزون صيدليتي، والحساسيات المعلنة، والموافقات، ومفاتيح المزامنة.
- كل الوصفات المحفوظة وبنودها ومراجعاتها (`ON DELETE CASCADE` + حذف صريح داخل معاملة واحدة).
- **ملفات صور الوصفات** من القرص (`data/uploads/prescriptions/…`).
- مواضيعه في المجتمع وردوده داخلها.
- ردوده في مواضيع الآخرين وبطاقات الوظائف وطلبات إضافة الأدوية: تبقى **بلا اسم** (فصل الحساب فقط)
  حتى لا تُهدم محادثات بقية المستخدمين.

**ما يبقى:** قيد واحد في سجل التدقيق (`account.delete`) بالبريد والدور والعدّادات — بلا أي كلمة مرور
وبلا صور. هذا مقصود: التدقيق يجب أن ينجو من الإمحاء.

بعد الحذف: تُلغى صلاحية التوكن فورًا (401)، والدخول بالبيانات القديمة يفشل (401).

### عبر الـAPI

```http
DELETE /api/auth/me          Authorization: Bearer <token>
POST   /api/auth/delete-account
{ "confirm": "DELETE", "password": "…" }

200 { "ok": true, "deleted": { "prescriptions": 2, "favorites": 5, "threads": 0, "pharmacy_items": 3, "allergies": 1, "photos": 2 } }
400 confirm-required · 403 wrong-password | owner-protected · 409 last-admin
```

## سجل التدقيق (`/admin?tab=audit`)

- `GET /api/admin/audit?limit=&offset=&action=&target=&q=&from=&to=` → `{data,total,limit,offset}`
- `GET /api/admin/audit/actions` → أسماء العمليات الفعلية وعدّ كل واحدة ونوع الهدف.
- `GET /api/admin/audit/verify` → `{ok:true,entries:n}` أو `{ok:false,broken_at,reason}`.

كل قيد يحمل `prev_hash` و`hash` (SHA-256 على الحمولة الأصلية). أي تعديل مباشر في قاعدة البيانات
يكسر السلسلة ويُكتشف بالزر. الشاشة تُظهر أيضًا معرّف الجهاز (IP) والبيانات الوصفية لكل عملية.

## الخصوصية

- الصور والوصفات لا تظهر لغير مالكها، إلا للصيدلي/المدير بغرض المراجعة (مسجّلة بالاسم).
- لا يوجد بيع أو مشاركة لبيانات مع أطراف ثالثة.
- التفاصيل الكاملة في `/legal/privacy` (`docs/PRIVACY.md`).
