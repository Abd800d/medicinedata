# لوحة التحكم · الخلاصة · Admin dashboard

> الشاشة الأولى في `/admin` (افتراضيًا) — وتُقرأ كلها من طلب واحد: `GET /api/admin/overview`.

## لماذا طلب واحد؟

قبل v1.11.0 كانت الأرقام موزّعة على `stats` و`diagnostics` و`ai-stats` وطابور المراجعة، فكل رقم من لحظة
مختلفة، وعلى شبكة الهاتف أربعة طلبات. الآن الخادم يجمع اللقطة في نفس اللحظة، والشاشة ترسمها كما هي.

## ماذا تعرض

| القسم | المحتوى | من أين |
| --- | --- | --- |
| درجة الصحة | نسبة من 100 = الفحوصات المكتملة ÷ الفحوصات **الإلزامية** (الاختيارية لا تُخصم) | `checks` |
| شرائط الهوية | إصدار الخادم، إصدار Node، مدة التشغيل، حالة AI وGoogle والصيانة | `platform` |
| بطاقات KPI | أدوية، منتجات، صور حقيقية (ونسبتها)، مستخدمون (+جديد هذا الأسبوع)، وكلاء، صيادلة | `content`, `people` |
| **ينتظر إجراءً منك** | وصفات في الطابور، طلبات إضافة، رسائل بلا رد إداري، أصناف منتهية، استيرادات فاشلة | `work` |
| قائمة التفعيل | 7 فحوصات: الكتالوج، الصور ≥70%، AI، الطابور، الطلبات، المخزون، Google (اختياري) | `checks` |
| نشاط 7 أيام | مستخدمون جدد + استدعاءات AI (أعمدة صغيرة بلا مكتبة رسوم) | `people.new_users_7d`, `ai.runs_7d_series` |
| الكتالوج والتخزين | أجهزة، تصنيفات، شركات، صور، حجم القاعدة، حجم المرفوعات، غير موثّق، حالة التسجيل | `content`, `platform` |
| آخر ما حدث | أكثر عمليات البحث + آخر 6 أحداث تدقيق | `activity` |

كل تنبيه وكل فحص يحمل رابطًا (`to`) إلى الشاشة التي تحلّه — لا تنبيه بلا مخرج.

## الـ API

```bash
# اللقطة كاملة (مدير فقط)
curl -s http://localhost:4000/api/admin/overview -H "authorization: Bearer $TOKEN"

# نفس الخلاصة كملف CSV (UTF-8 مع BOM ليفتح صحيحًا في Excel العربي)
curl -s http://localhost:4000/api/admin/overview.csv -H "authorization: Bearer $TOKEN" -o overview.csv
```

| الحقل | المعنى |
| --- | --- |
| `health.score` | 0–100 من الفحوصات الإلزامية فقط |
| `health.optional_failed` | فحوصات اختيارية غير مضبوطة (لا تُخصم) |
| `content.images` | `with_image` / `total` / `percent` / `missing` — صورة حقيقية = `image_url` أو صف في `product_images` ليس `generated` |
| `work.rx_pending_review` | عدد الوصفات التي فيها بند `pending` (نفس تعريف طابور المراجعة) |
| `work.pharmacy_expired` | أصناف تاريخ انتهائها قبل اليوم |
| `ai.enabled` | من `getAiConfig().configured` — نفس ما يقرأه المحلل، لا نسخة ثانية |
| `platform.uptime_s` | `process.uptime()` — لا تخمين من وقت تحميل وحدة |
| `alerts[].level` | `danger` / `warn` / `info` |

## ما لا تفعله الشاشة

- لا تعرض `password_hash` ولا `jwt_secret` ولا أي مفتاح: الاستعلامات لا تختارها أصلًا.
- لا تُظهر صفرًا مكان قيمة غير متاحة؛ تعرض «—».
- لا تشغّل مؤقتات خفية: التحديث التلقائي (60 ثانية) يُشغّل بزر ويُوقف بزر.
