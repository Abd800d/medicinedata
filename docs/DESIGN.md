# الهوية البصرية · Design system

واجهة MDA مبنية على هوية واحدة: **أزرق منتصف الليل + أزرق كهربائي/سماوي**، زجاج داكن،
وأيقونات ملوّنة متدرجة — نفس روح الشاشة المرجعية (Splash / Home / Medicines / Product).

| `ink-900` | `#0a1930` | البطاقات والأسطح |
| `ink-400` | `#7f9dc9` | نص ثانوي |

التدرّجات الجاهزة: `bg-brand-grad` (زر/شعار)، `.hero-card`، `.page-hero` (+ `-violet`, `-emerald`,
`-amber`, `-rose`)، و`bg-tile-grad` للأسطح.

## 3) الشاشات

- **Splash** → شعار MDA + «جميع الأدوية في مكان واحد».
- **الرئيسية** → Hero (بحث + إحصاءات) ← 8 أدوات ← 12 جهازًا ← بانر المساعد الذكي ← منتجات حقيقية ← أدوية شائعة ← الثقة.
- **الأجهزة / جهاز واحد** → شبكة أيقونات ملوّنة، ثم تصفية بالتصنيفات وبحث داخلي.
- **الأدوية والمنتجات** → بطاقات بصور حقيقية على طبق أبيض، شارة MDA للموثّق.
- **تفاصيل المنتج** → معرض صور + شرائح (Genuity/Form/Strength/Price) + الشركة/الوكيل + الباركود.
- **الوصفات / المسح / المساعد** → رأس ملوّن مخصّص لكل شاشة (`page-hero-*`).
- **لوحة التحكم** → نفس الهوية مع تبويبات متدرجة.

## 4) الأيقونات والتطبيق

```bash
bash scripts/make-icons.sh     # يعيد توليد كل الأيقونات (ويب + أندرويد) من شعار MDA
```

- أيقونة الويب: `public/icons/*` + `public/favicon.png`.
- أندرويد: `android/app/src/main/res/mipmap-*/ic_launcher*.png`، خلفية الأيقونة التكيفية `#0A2560`.
- شاشة البداية الأصلية: `#050C1A` (في `styles.xml` و`capacitor.config.ts`).
- PWA: `theme_color` و`background_color` = `#050c1a`.

## 5) قواعد عملية

- **جوال أولًا**: كل تصميم يبدأ بعرض 390px ثم يتوسّع (`sm/lg`).
- لا تستخدم `h-4.5` أو قيمًا غير موجودة في `tailwind.config.js` (أضِف `spacing` عند الحاجة).
- النصوص على الأسطح الداكنة: `text-white` للعناوين، `text-ink-300/400` للتفاصيل.
- الأيقونات الملوّنة: مربّع `rounded-[14px]–[18px]` + تدرّج + `ring-1 ring-white/20` + `shadow-tile`.
- الحركة: `animate-fade-up` للظهور، `animate-rise` للأقسام الرئيسية، وتُعطَّل تلقائيًا مع
  `prefers-reduced-motion`.
- الوضع الفاتح غير مُفعَّل: المنتج بهوية داكنة واحدة (مثل الشاشة المرجعية) لتفادي تباين ضعيف.
