# لقطات شاشة المتجر (اختياري)

ضع هنا لقطات حقيقية من التطبيق المثبّت على الهاتف (`*.png` أو `*.jpg`)، ثم:

```bash
npm run store:assets
```

فيُنتج `store/screenshots/shot-N.png` بمقاس **1080×1920** بدون شفافية (جاهزة لـGoogle Play).

- Google Play يقبل أيضًا اللقطات الخام كما هي — الإطار هنا تجميلي فقط لتوحيد المظهر.
- لا تُرفع لقطات من متصفح الحاسوب: اللجنة تراجع تجربة الهاتف.
- المجلد `store/screenshots/` مُستثنى من Git (ناتج مُشتق من صورك).

اللقطات المقترحة (٦ صور): الرئيسية · بحث/قائمة أدوية · صفحة دواء بالصور · شاشة الوصفات
(زر منع لقطات الشاشة ظاهر) · نظام حيوي مع المنتجات · لوحة الإدارة.
