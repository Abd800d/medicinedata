## نظرة عامة

MDA منصة دوائية واحدة تجمع:

- **قاعدة أدوية حقيقية** ثنائية اللغة (18 جهازًا حيويًا، 137 تصنيفًا دوائيًا، 225 اسمًا علميًا بمونوغراف كامل).
- **493 منتجًا تجاريًا** مرتبطًا بالاسم العلمي، مع الشركة المصنّعة، التركيز، الشكل الصيدلاني، الدولة، ووكيل/موزّع اليمن.
- **بحث ذكي** يتحمّل الأخطاء الإملائية والكتابة العربية/الإنجليزية (trigram FTS5 + تشابه نصي).
- **وصفات طبية بالصور** + محلّل محلي يعمل دون إنترنت، مع طبقة AI اختيارية عند توفير مفتاح.
- **صيدليتي**: إدارة مخزون الصيدلية (كميات، أسعار شراء/بيع، تواريخ انتهاء، موردون، تنبيهات نفاد وصلاحية).
- **إضافة دواء يدويًا** من المستخدمين مع مراجعة إدارية قبل النشر في القاعدة.
- **مجتمع ودعم** (رسائل عامة/خاصة مع الإدارة)، **لوحة وظائف**، **دليل شركات ووكلاء**.
- **لوحة إدارة كاملة**: CRUD، استيراد CSV/Excel/JSON، استيراد صور بالجملة، إدارة المستخدمين والرسائل، إعدادات، تصدير نسخة احتياطية.
- **عربي/إنجليزي كامل** مع RTL، ووضع ليلي، وتصميم جوال أولًا.

## المزايا

| المجال | التفاصيل |
| --- | --- |

## التقنيات

- **الواجهة:** React 18 + TypeScript + Vite 5 + Tailwind CSS 3 + lucide-react + react-router 6
- **PWA:** vite-plugin-pwa (Workbox) — تثبيت على الشاشة الرئيسية وعمل دون اتصال
- **الخادم:** Node.js 20+ · Express 4 · better-sqlite3 (SQLite + WAL + FTS5 trigram)
- **المصادقة:** JWT (jsonwebtoken) + bcryptjs + Google Identity Services
- **الرفع:** multer (صور المنتجات، الوصفات، المسح، الاستيراد)
- **الاستيراد:** CSV يدوي/Excel (xlsx) / JSON
- **الأندرويد:** Capacitor 6 (`android/` مُهيّأ بالكامل)

## التشغيل السريع

```bash
# 1) المتطلبات: Node.js >= 20 و npm
node -v

# 2) التثبيت
npm install

# 3) الإعدادات (انسخ ثم عدّل)
cp .env.example .env
#   - غيّر JWT_SECRET و ADMIN_PASSWORD قبل الإنتاج

# 4) تهيئة القاعدة + البيانات المرجعية
npm run seed          # إنشاء data/mda.db وتعبئته (18 جهازًا، 137 تصنيفًا، 225 دواءً، 493 منتجًا، 105 شركات، 24 وكيلًا)
# أو لتصفير الكتالوج وإعادة بنائه:
npm run seed:reset

# 5) التطوير (API + واجهة Vite)
npm run dev           # http://localhost:5173  (API على 4000)

# 6) الإنتاج
npm run build && npm start   # http://localhost:4000
```

**حساب المدير** يُنشأ تلقائيًا من `OWNER_EMAIL` + `ADMIN_PASSWORD` (الافتراضي في التطوير `7a8b1d@gmail.com` / `MDAadmin@2026`). **غيّرهما قبل أي نشر.**

## قاعدة البيانات والبيانات المرجعية

- الملف: `data/mda.db` (SQLite، WAL). غير مُضمَّن في Git — يُنشأ بـ `npm run seed`.
- الجداول: `systems, categories, drugs, products, product_images, manufacturers, agents, users, threads, messages, jobs, favorites, prescriptions, imports, settings, pharmacy_items, drug_submissions`.
- البحث: جدول FTS5 (trigram) + عمود `search_norm` مُطبَّع، يُعاد بناؤه من **الإدارة → الإعدادات → مزامنة البحث**.
- تفاصيل النموذج والمصادر في [`docs/DATA.md`](docs/DATA.md).

## لوحة الإدارة

`/admin` (تظهر للمدير فقط):

- **لوحة المعلومات:** إحصاءات الكتالوج والمستخدمين والرسائل، تشخيص الخادم، تصدير نسخة JSON.
- **قاعدة الأدوية:** CRUD للأجهزة/التصنيفات/الأدوية/المنتجات/الشركات/الوكلاء + رفع صور المنتجات وربط صورة من الويب.
- **الاستيراد والصور:** استيراد CSV/Excel/JSON (معاينة قبل التنفيذ، سجل عمليات)، استيراد صور بالجملة، فحص المنتجات بدون صورة.
- **المستخدمون والرسائل:** تغيير الصلاحية/التعطيل/كلمة المرور، الرد على رسائل الدعم ونشر الرد للجميع.
- **طلبات الإضافة:** اعتماد أو رفض الأدوية المرسلة من المستخدمين؛ الاعتماد يُنشئ الدواء (والمنتج) في القاعدة فورًا.
- **الإعدادات:** بيانات التطبيق والمالك والتواصل، إخلاء المسؤولية، تفعيل التسجيل والصيانة، مفاتيح AI/Google، مزامنة البحث.

الأعمدة المطلوبة للاستيراد موثّقة في [`docs/IMPORT.md`](docs/IMPORT.md).

## الوصفات الطبية والصور

- **بدون مفتاح AI:** يعمل المحلّل المحلي بالكامل — يستخرج أسماء الأدوية من النص ويطابقها مع المنتجات (اسم تجاري/علمي/عربي) ويعرض البدائل والتحذيرات. مناسب للاستخدام دون إنترنت.
- **مع مفتاح AI:** تُقرأ الصورة عبر نموذج رؤية (vision) متوافق مع OpenAI API، ثم تُطابَق النتائج محليًا بقاعدة البيانات (لا تُختلق أدوية غير موجودة).
- **صور المنتجات:** 27 صورة حقيقية لـ18 منتجًا مرفقة داخل المشروع (`public/seed-images/products/`)، تُطبَّق تلقائيًا عند `npm run seed`. الباقي يمكن جلبه من Google Programmable Search (`npm run images:fetch`) أو رفعه من الإدارة. في غياب صورة حقيقية يظهر رسم تعبئة SVG مولّد.
- **الباركود:** كل منتج له EAN-13 صالح للمسح (بادئة 20–29 المحجوزة للاستخدام الداخلي) مع تمييز واضح أنه غير مطبوع على العلبة، ويُستبدل بباركود الشركة عند إدخاله. المسح يعمل من صفحة `/scan` بمحرّك مزدوج (BarcodeDetector أو ZXing) وإدخال يدوي.

## حدود النسخة الحالية

- **مفتاح AI اختياري:** بدون مفتاح يعمل كل شيء محليًا (بحث/مطابقة/صيدلي)، لكن قراءة الوصفات من الصور تتحول إلى إدخال نصي يدوي.
- **الصور:** القاعدة المرجعية لا تحتوي صورًا حقيقية لكل منتج؛ تُستخدم صور مرفوعة من الإدارة أو رسوم تعبئة مولّدة.
- **الأندرويد:** يحتاج Android SDK/Gradle على جهازك لبناء APK (لا يُبنى داخل هذا المستودع).
- البيانات المرجعية تغطي الأدوية الشائعة في اليمن/الخليج ومصر/الشام؛ التوسّع يتم من لوحة الإدارة أو الاستيراد.

## English summary

**MDA — MedicineData** is a mobile-first, bilingual (Arabic/English, RTL) pharmaceutical reference and pharmacy-management app built for Yemen and the Arab market. It ships with 18 body systems, pharmacological classes, generic monographs, commercial products with manufacturer/country/Yemeni agent, fuzzy multilingual search, offline packs, prescription-photo analysis (offline matcher + optional OpenAI-compatible vision), personal pharmacy stock, community support, a job board, a manufacturer/agent directory, and a full admin panel (CRUD, CSV/Excel/JSON import, bulk image import, users, messages, settings, backup export). Stack: React 18 + Vite + Tailwind + Express + SQLite (better-sqlite3 + FTS5). Android via Capacitor (`android/`). See [`docs/`](docs) for deployment, environment, Android and import guides.

### يعمل بدون خادم (بيانات مدمجة)

الحزمة `public/data/catalog.json` تُولَّد من قاعدة البيانات وتُدمج **داخل التطبيق**، لذا يعمل
التطبيق كاملًا بعد التثبيت مباشرةً حتى بدون إنترنت أو خادم:

| يعمل بلا خادم | يحتاج خادمًا |
|---|---|
| 18 جهازًا · 137 تصنيفًا · 225 دواءً · 493 منتجًا | المجتمع والوظائف |
| البحث العربي/الإنجليزي مع تحمّل الأخطاء الإملائية | الصيدلية والمخزون |
| مسح الباركود ومعرض الصور الحقيقية | لوحة التحكم `/admin` والاستيراد |
| صور العلب المولّدة تلقائيًا + دليل الشركات والوكلاء | قراءة الروشتة بالذكاء الاصطناعي |

تحديث الحزمة بعد تغيير البيانات:

```bash
npm run seed          # يعيد البناء تلقائيًا في النهاية
# أو
npm run bundle:data   # من data/mda.db إلى public/data/catalog.json
```

> محرّك البحث وتوليد الصور **نفس الوحدات** التي يستخدمها الخادم (`server/lib/*` تُنسخ إلى
> `src/lib/core` عند كل بناء)، فلا يختلف البحث أو الشكل بين الوضعين.
